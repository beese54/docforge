What OpenShell enforces

  • Landlock: the agent can write only inside /sandbox; system paths are read-only.
  • seccomp: dangerous system calls are refused (it even stops Chromium creating namespaces).
  • Egress proxy: one allowed host, api.anthropic.com, where the real key is added.

What docforge adds

  • The agent can write only README.md, CHANGELOG.md and docs/**.md; secret files are unreadable.
  • A budget guard sizes every model call so no run exceeds its cap.
  • apply re-checks every path, and pushes are limited to docforge/* branches.
